1. Pengertian Komputasi Awan (Cloud Computing)

Komputasi Awan (Cloud Computing) adalah model penyediaan sumber daya komputasi-seperti server, media penyimpanan (storage), basis data, jaringan, hingga perangkat lunak aplikasi-melalui jaringan internet (cloud) secara sesuai permintaan (on-demand). Dengan komputasi awan, pengguna maupun organisasi tidak perlu lagi membeli, merakit, dan memelihara server fisik sendiri di lokasi lokal (on-premise), melainkan cukup mengakses layanan yang dikelola oleh penyedia layanan cloud dari mana saja selama terhubung ke internet.

Dalam konteks publikasi website statis pada tugas ini, GitHub Pages merupakan contoh nyata pemanfaatan infrastruktur cloud hosting: berkas HTML, CSS, dan gambar disimpan di server milik GitHub dan disajikan langsung kepada pengunjung melalui alamat URL publik yang selalu aktif 24 jam sehari tanpa bergantung pada komputer lokal mahasiswa.

2. Tiga Model Layanan Utama: SaaS, PaaS, dan IaaS

SaaS
(Software as a Service)

Layanan perangkat lunak siap pakai yang dijalankan langsung melalui peramban web tanpa instalasi maupun pengelolaan server oleh pengguna. Pengguna hanya menggunakan fitur aplikasi dan mengelola datanya sendiri.

Contoh: Google Drive, Google Docs, Gmail, Microsoft 365, Canva.

PaaS
(Platform as a Service)

Layanan yang menyediakan lingkungan/platform siap pakai bagi pengembang untuk membangun, menguji, dan mempublikasikan (deploy) kode aplikasi tanpa perlu mengonfigurasi sistem operasi atau perangkat keras server.

Contoh: GitHub Pages, Google App Engine, Vercel, Netlify, Heroku.

IaaS
(Infrastructure as a Service)

Layanan penyewaan infrastruktur komputasi dasar berupa mesin virtual (Virtual Machine), kapasitas penyimpanan, dan jaringan. Pengguna memiliki kendali penuh atas sistem operasi dan perangkat lunak yang dipasang.

Contoh: Amazon EC2 (AWS), Google Compute Engine (GCP), DigitalOcean Droplets.
Model Layanan Apa yang Dikelola Penyedia Cloud Apa yang Dikelola Pengguna Contoh Penggunaan Nyata
SaaS Seluruh infrastruktur, jaringan, penyimpanan, sistem operasi, runtime, hingga kode aplikasi. Penggunaan aplikasi dan berkas/data milik pengguna sendiri. Menyimpan dokumen tugas di Google Drive atau mengedit laporan di Google Docs.
PaaS Server fisik, penyimpanan, jaringan, sistem operasi, serta lingkungan build & hosting otomatis. Kode sumber aplikasi/website (HTML, CSS, JS) dan konfigurasi repositori. Mempublikasikan website statis mahasiswa melalui GitHub Pages.
IaaS Pusat data fisik (data center), rak server, jaringan fisik, dan lapisan virtualisasi. Sistem operasi (Linux/Windows), konfigurasi web server (Nginx/Apache), basis data, dan kode. Menyewa VPS / Virtual Machine di AWS EC2 atau Google Compute Engine.

3. Manfaat dan Risiko Penggunaan Layanan Cloud

Aspek Manfaat Penggunaan Layanan Cloud Risiko & Cara Menguranginya (Mitigasi)
Ketersediaan & Aksesibilitas Website dan data dapat diakses kapan saja (24/7) dari perangkat apa pun melalui URL publik meskipun laptop pemilik dimatikan. Risiko: Ketergantungan pada koneksi internet dan potensi gangguan (downtime) penyedia.
Mitigasi: Menyimpan salinan cadangan (backup ZIP) di perangkat lokal.
Biaya & Pemeliharaan Menghemat biaya pembelian server fisik dan listrik karena infrastruktur dikelola sepenuhnya oleh penyedia cloud. Risiko: Keterikatan pada satu penyedia layanan (vendor lock-in) atau batasan kuota.
Mitigasi: Menggunakan format web standar (HTML/CSS) yang mudah dipindahkan.
Kemudahan Deployment & Pembaruan Versi Perubahan kode (seperti pembaruan Versi 1 ke Versi 2) dapat langsung dipublikasikan ulang ke alamat URL yang sama dalam hitungan menit. Risiko: Kesalahan commit yang menimpa tampilan publik secara langsung.
Mitigasi: Menguji website secara lokal di peramban sebelum mengunggah ke repositori.
Keamanan & Privasi Data Publik Repositori publik memudahkan kolaborasi terbuka dan pemeriksaan hasil tugas oleh dosen tanpa hambatan izin akses. Risiko: Kebocoran data sensitif (kata sandi, API key, nomor identitas/KTP, atau nomor telepon pribadi) karena dapat dilihat siapa saja.
Mitigasi: Menyensor data kontak sensitif dan tidak pernah mengunggah kredensial rahasia ke repositori publik.
